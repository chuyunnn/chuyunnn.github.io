创建应用：

  1. 输入目标页面场景（如「在线表单」「商品展示页」）
  2. 描述页面整体框架（如「顶部导航栏 + 中部内容区 + 底部按钮」）
  3. 提供清晰、详细的需求提示
  4. 拆分复杂需求，避免长文本输入，降低模型理解偏差
  5. 发送指令，等待生成结果

如果需要持续修改页面：

  1. 输入时，尽量清晰地描述要修改的具体位置，以便更准确地实现修改需求。
  2. 页面一些 AI 无法知道的信息我们要表述清楚，包括页面内的文字、跳转链接等。
  3. 若修改信息较多，建议分点描述或分次进行调整，确保修改内容的准确性和完整性。

除了文本内容，还能为作品增添图片元素来提升视觉效果！具体操作如下：

  1. 点击输入框中的「上传」按钮，选择您想添加的图片；

  2. 告知模型图片需要插入的位置（例如：“请将图片添加到第一段末尾”），模型会协助您完成排版，让作品更美观。

  3. 结构化“全能”框架

如果你想从零开始构建一个功能，推荐使用这个模板：

  • Role (角色): 你是世界顶级的 [技术栈] 开发者。
  • Vibe (风格): 界面要像 Linear 一样简洁，交互要像 Apple 一样流畅。
  • Task (任务): 帮我写一个 [具体功能]。
  • Constraints (约束): 响应式、支持深色模式、不要冗余代码。
  1. 描述“感觉”而非逻辑

在 Vibe Coding 中，你可以多用形容词。AI 对这些视觉和交互属性的理解已经非常强了。

  • 视觉提示词：

    “给我做一个登录页面，要 Glassmorphism（玻璃拟态） 风格，背景要有那种 极光流动的渐变感，字体用 Inter，看起来要很贵、很高级。”

  • 交互提示词：

    “给这个按钮加一个 弹簧动画。用户点击时，按钮要稍微收缩再弹回，反馈要非常 Snappy（干脆利落）。”

  1. “我有一个想法”型（快速原型）

如果你只有一个模糊的念头，可以尝试“倒逼”AI 给你方案：

“我想做一个记录心情的极简 App。不要复杂的表单，只需要用户选一个颜色代表今天的心情。请基于这个 Vibe 帮我构思 UI 布局，并直接输出可运行的 React + Tailwind 代码。”

  1. 调试与重构（Vibe Check）

当你觉得代码写得“太烂”或“太重”时：

  • 重构提示词：

    “这段代码现在的逻辑太啰嗦了。请用 更优雅、更函数式 的写法重写它。保持代码的可读性，像写诗一样简洁。”

  • 找茬提示词：

    “检查一下这个页面的 UX Vibe。有没有哪里操作起来觉得反人类？请直接修改代码优化掉。”
