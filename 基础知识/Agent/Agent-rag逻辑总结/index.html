停止输出

使用stopFlags： 给每个 WebSocket 连接加一个【停止开关】

  • final：不可修改这个map为其他map，可以赋值

流程：谁连接了，就给它开一个开关 ==> 前端点停止按钮 → 把这个开关改成 true ==> 后端代码每走一步，都先看一眼开关 ==> 发现是 true → 立刻停下，不再发消息

模型管理：AgentModelRouter

src/main/java/com/yizhaoqi/searchSmart/agent/service/AgentModelRouter.java

缓存池：先根据名称查找有没有创建好的chatclient对象，如果有直接用就行

如果没有：创建对象（根据配置文件，无需chatclient硬编码，只要配置文件有就能加载出来）

  • chatmodel：最底层、最核心的调用入口
  • chatclient：把chatmodel包装了一层，链式调用

消息接收

runAsync()表示开一个子线程跑doProcessMessage()这个复杂任务

  • 主线程（Websocket连接线程）立即返回，不等待
    • 后续任务很庞大很慢，不让websoket阻塞

后续流程：doProcessMessage()

获取会话ID（上下文） ==> 获取模型会话，选择使用哪个模型 ==> 根据会话id，获取上一轮会话快照 ==> 执行Agent循环 ==> 检查是否点击停止按钮 ==> 流失推送用户回答 ==> 是否停止 ==> 用户问题+ai回答存入chatmemory ==> 构建对话完整快照，保存会话快照 ==> 存入数据库 ==> 返回消息给前端
