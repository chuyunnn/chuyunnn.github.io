Linux 系统监控与管理指令合集

1. 进程监控与管理

命令 核心功能 高频参数 / 示例 特点说明
top 实时查看进程、CPU、内存占用 top 静态动态刷新，默认 3 秒更新一次
htop 交互式进程查看器 htop 界面更友好，支持鼠标操作、横向纵向滚动
ps 查看当前进程快照 ps -ef / ps aux 静态展示，aux为常用全量格式
pgrep 按名称查找进程 ID pgrep redis 快速定位进程 PID，无需复杂过滤
pstree 以树状显示进程关系 pstree 清晰展示父子进程结构

2. 系统资源与负载

命令 核心功能 高频参数 / 示例 特点说明
uptime 系统运行时间、平均负载 uptime 核心关注load average（1/5/15 分钟负载）
vmstat 虚拟内存、进程、CPU 统计 vmstat 2 3 每 2 秒采样 1 次，共 3 次，监控整体资源
sar 系统性能统计（长期 / 历史） sar -u 2 5 每 2 秒采样 1 次，共 5 次，输出 CPU 使用率
free 内存使用详情 free -h 以人类可读格式（GB/MB）显示内存 / 交换区

3. 磁盘与文件存储

命令 核心功能 高频参数 / 示例 特点说明
df 磁盘空间总量与使用量 df -h / df -a 按文件系统统计，-h为人性化显示
du 目录 / 文件占用空间 du -sh /var 统计/var目录总大小，-s汇总，-h人性化

4. 服务与系统管理

命令 核心功能 高频参数 / 示例 特点说明
systemctl 系统服务管理 systemctl status redis``systemctl restart redis 管理服务状态、启动、停止、重启

高频组合使用场景（实战必备）

  1. 查找 Redis 进程并终止

  2. 持续监控 CPU 使用率（sar 长期记录）

  3. 快速排查磁盘空间不足

  4. top指令内容：

看系统负载：load average + %Cpu(s) id

看内存是否够用：Mem avail Mem + Swap used

找耗资源进程：%CPU / %MEM 列排序

排查僵尸进程：Tasks zombie 列
